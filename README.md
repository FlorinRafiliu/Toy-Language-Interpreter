# Toy Language Interpreter

  - Application written for the Advanced Programming Methods course @ Babes-Bolyai University.
  - Programming language: Java, JavaFx Framework(GUI);
  - App for interpreting the instructions of a language similar to Java/C;
  - Supports synchronization mechanism and multi-processing ("fork").

  Some of the skills I developed while working on this applications are:
1. Exception Handling & Validation: Built validation mechanisms and custom exception classes to handle errors in repository operations, input validation, and data processing.
2. TypeChecking
3. Functional Programming in Java
5. MVC architecture
6. GUI Development with JavaFx: Designed a graphical interface in JavaFx
7. UML Design: Created a UML class diagram to document and visualize the architecture, improving project organization and communication
8. A better understanding of how an interpreter work.
